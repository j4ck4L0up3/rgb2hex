# rgb2hex

A simple script for converting rgb to hexidecimal from the cli because I got tired of looking it up.

If you install the binary from release, put in a place where you can use it like `~/.local/bin` or `/usr/local/bin/` (assuming you're using Linux).

Make it executable:
`chmod +x rgb2hex`

Example usage:
`rgb2hex 115 239 247`

Example output:
`#73EFF7`
